# Mon suivi quotidien — PWA

## GitHub Pages
1. Créer un dépôt GitHub.
2. Déposer tout le contenu de ce dossier à la racine.
3. Settings → Pages.
4. Source : Deploy from a branch.
5. Branch : main ; dossier : /(root).

## Smartphone
- iPhone : Safari → Partager → Sur l’écran d’accueil.
- Android : Chrome → ⋮ → Installer l’application / Ajouter à l’écran d’accueil.

Ne jamais ajouter une clé Supabase secrète ou service_role dans GitHub.
